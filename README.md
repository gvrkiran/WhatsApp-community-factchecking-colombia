# WhatsApp-community-factchecking-colombia

Supplementary materials for the WhatsApp community fact-checking study in Colombia.

## Contents

- `Data - WoC Fieldwork.xlsx` — fieldwork data.
- `Demographic Data.xlsx` — demographic data.
- `Interview Notes - WoC Pilot.docx` — pilot interview notes.
- `Interviews Transcription (Spanish).docx` — Spanish interview transcriptions.
- `stimuli/` — images and videos used as study stimuli, organized by week.

## Notes

Files in this repository are supplementary research materials. Please preserve the existing filenames and directory structure when using or citing them.
